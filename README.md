## セットアップ

本体へ、以下の順でセットアップします。

### 実機で、PC-Gリンク等の転送ソフトをお使いの場合

* BASICモードから`MON`で機械語モニタを起動し、`USER 3F5F`と入力してEnterキーを押し、機械語のユーザーエリアを確保します。
* `R`と入力してEnterキーを押すと、プログラムファイル（`yakyuken.hex`）が転送されます。
* `R`と入力してEnterキーを押すと、データファイル（`data.hex`）が転送されます。

### SHARP PC-G850/G815/E200エミュレータ g800をお使いの場合

#### 実機ROMファイルがある場合

* g800を起動します。
* BASICモードから`MON`で機械語モニタを起動し、`USER 3F5F`と入力してEnterキーを押し、機械語のユーザーエリアを確保します。
* エクスプローラーからg800のウインドウへ、プログラムファイル（`yakyuken.hex`）をドラッグ&ドロップすると、g800へ転送するファイルがセットされます。
* `R`と入力してEnterキーを押すと、ドロップしたファイルが転送されます。
* エクスプローラーからg800のウインドウへ、データファイル（`data.hex`）をドラッグ&ドロップすると、g800へ転送するファイルがセットされます。
* `R`と入力してEnterキーを押すと、ドロップしたファイルが転送されます。

#### 実機ROMファイルが無い場合

* g800を起動します。
* BASICモードから`MON`で機械語モニタを起動し、`USER 3F5F`と入力してEnterキーを押し、機械語のユーザーエリアを確保します。
* エクスプローラーからg800のウインドウへ、プログラムファイル（`yakyuken.hex`）をドラッグ&ドロップすると、ファイルが転送されます。
* エクスプローラーからg800のウインドウへ、データファイル（`data.hex`）をドラッグ&ドロップすると、ファイルが転送されます。

## 起動方法

BASICモードから`MON`で機械語モニタを起動し、`G100`で起動します。<br>
または、BASICモードから`CALL &H100`でも起動できます。<br>

## ゲームのルール

一般的な野球拳のルールをベースにした、リアルタイム・アクティブじゃんけんです。

### 基本ルール

* 画面のメッセージとBGMに合わせてじゃんけんをします。
* 「よよいのよい！」のタイミングで、最終的に決定されていた手で勝負が決まります。
* プレイヤーの服は４枚、女の子の服は５枚です。

### リアルタイム変更システム

* 「よよいのよい！」までのフレーズの間、プレイヤーも女の子も、出す手をリアルタイムに何度も変更可能です。
* 女の子の迷いや手の動きを予測しながら、タイミングを合わせてキーを入力してください。
* 女の子の出す手は、単なるランダムではなく、プレイヤーの手を読んだり、心理戦を図ったりします。

### エンディングとご褒美

* 女の子の服をすべて脱がすと、エンディングへ移行します。
* 画面に特別なご褒美メッセージが表示されます。頑張ってください！

## 操作方法

### 《タイトル画面》

| キー | 役割 |
|------|------|
| `Sキー` | 音のOFF/ONの切り替え<br> ※本体に圧電ブザーが取り付けられていない場合、ONにしても音は鳴りません。 |
| `SPACEキー` | ゲームスタート |

### 《ゲーム》

| キー                        | 出す手 |
|-----------------------------|--------|
| `1`・`4`・`7キー`のいずれか | グー   |
| `2`・`5`・`8キー`のいずれか | チョキ |
| `3`・`6`・`9キー`のいずれか | パー   |
| `SPACE` または `Enterキー`  | メッセージ表示後、次へ進みます。 |
| `Pキー`                     | パニックモード（ボスが来た）の切り替え<br> `SPACE` または `Enterキー`を押すと元の画面に復帰します。 |
| `Sキー`                     | 音のOFF/ONの切り替え<br> ※本体に圧電ブザーが取り付けられていない場合、ONにしても音は鳴りません。 |

## 終了方法

本体の`BASICキー`・`TEXTキー`・`OFFキー`・`Qキー`のいずれかを押してください。<br>

## うまく動作しない場合

一度、本体の電源を切り、再度起動してください。<br>

## その他

* 音を出したい場合、本体へ圧電ブザーを取り付ける必要があります。<br>
圧電ブザーの取り付け方法につきましては、[作者のWebSite](http://yswgt879.blog.fc2.com/blog-entry-360.html)か、各種サイトにてご確認ください。<br>
* SHARP PC-G850/G815/E200エミュレータ g800から動作させる場合、実機ROMが無いと、入力が若干遅かったり、音割れが発生する等の問題があります。<br>
音割れが気になるようであれば、サウンドはOFFにしてください。<br>
* PC-G850/G850S/G850Vにて、動作を確認しております。<br>
他機種（PC-G850VS）での動作も可能かと存じますが、検証が取れておりません。<br>
万一、動作に支障がございましたら、ご一報頂けると幸いに存じます。
